THE PRINCIPLE

The bus doesn't stop until you ship.

INTRODUCING

Ultrathink Studio

The bus you ride.

Cross-platform desktop app. Wraps your AI of choice — Claude, Codex, GPT-5, Ollama — and gives them the full Ultrathink toolbox the moment you start typing.

🚌 The Fleet

230+ passengers, auto-boarded per trip.

  • Skill mesh — orchestrators, hubs, utilities, domain specialists. Each prompt picks the right ones.
  • Visible routing — the badge row above your chat shows exactly which passengers got on this turn.
  • Linked skills — boarding one pulls related ones via linksTo in the registry.

🚏 Bus Stops

Pick up new passengers from any GitHub repo.

  • install-pack.sh — clones, finds skills, symlinks them in. Your next prompt sees them.
  • One command away from someone else's pipeline being yours too.
  • Optional name prefix when two packs collide. No registry, no review board.
# Pick up a new pack at any stop:
./scripts/install-pack.sh https://github.com/acme/awesome-skills

# Or with a prefix to avoid collisions:
./scripts/install-pack.sh https://github.com/acme/awesome-skills acme-

# That's it. Next prompt sees them.
